# 전국 대비 인천시 아동 실종신고 추이 비교

## 프로젝트 개요
데이터 분석 학습을 위한 두번째 연습 프로젝트입니다.
전국 실종아동 발생 현황 데이터와 이전에 분석한 인천시 데이터를 활용해 연도별 추이를 분석합니다.

## 사용 데이터
- 전국: 공공데이터포털 - 경찰청_연도별 실종아동등 가출인 접수 및 해제현황
  (https://www.data.go.kr/data/15129413/fileData.do)
  - 데이터 기간: 2021년 - 2025년
- 인천: 공공데이터포털 - 경찰청_인천광역시경찰청_아동 실종신고 현황
  (https://www.data.go.kr/data/15041727/fileData.do)
  - 데이터 기간: 2017년 - 2025년 (이번 비교에는 2021 - 2025년만 사용)
- 인천 : 주민등록 인구통계 행정안전부 - 202112_202512_주민등록인구및세대현황_연간
  (https://jumin.mois.go.kr/)
    - 데이터 기간 : 2021년 - 2025년

## 비교 기준
전국 데이터는 18세 미만 아동, 지적장애인, 치매환자, 가출 성인이 함께 집계되어 있어, 그중 `18세_미만_아동_접수` 컬럼만 추출하여 인천 아동 데이터와 동일한 기준으로 비교함
